# Introduction 

A python class which illustrates crystal structures.

A crystal structure is uniquely specified by the Bravais lattice and a basis. 
Hence, the class takes as input the name of the Bravais lattice, the lattice constants of the conventional unit cell and the positions of the atoms / ions in the structure, its radi, names and desired colors.

All lengths are measured in Angstrom. (Unfortantly, plots are not to scale. Needs to be fixed.)

This Project is in its early phase and there are many ideas to expand it.
